# ItemThrower (клиентский мод, Fabric 26.1.2)

Автоматически выбрасывает назначенный предмет из инвентаря вперёд по направлению
взгляда — удобно поставить воронки перед собой и собирать, например, изумруды
от торговли с жителем прямо во время торговли. Работает только на клиенте,
серверу ничего не нужно: мод просто повторяет обычное действие "выбросить
предмет из слота" (то же самое, что происходит при наведении на слот и
нажатии Q), в том числе **пока открыт инвентарь или окно торговли**.

## Как пользоваться

1. Возьмите в руку предмет, который нужно выбрасывать (например, изумруд),
   нажмите кнопку **"Назначить предмет"**.
2. Нажмите кнопку **"Вкл/выкл авто-выброс"** — готово. Пока включено, мод
   каждые несколько тиков проверяет инвентарь и выбрасывает найденные стопки
   назначенного предмета, одну за другой.
3. Повторное нажатие той же кнопки — выключает.

Обе кнопки — в **Настройки → Управление → ItemThrower**, по умолчанию не
назначены, задайте сами.

Предмет можно (пере)назначить в любой момент, в том числе во время торговли —
просто переложите нужный предмет в руку (например, щёлкнув по нему мышью в
открытом окне торговли/инвентаря) и нажмите кнопку снова.

## Команды

```
/itemthrower on | off | status
/itemthrower item   — назначить предмет, который сейчас у вас в руке
```

## Как это работает

Мод не ломает блоки, не кликает по экрану и не управляет персонажем — он
просто временно "превращает" выбранный слот с нужным предметом в клик
правой... точнее, в клик типа "выбросить" (как Q), той же командой, которую
обычно отправляет клиент при наведении на слот и нажатии Q. Благодаря этому
работает одинаково:
- в обычном инвентаре (даже если он не открыт на экране),
- в открытом окне торговли с жителем (эмеральды после сделки уже лежат в
  вашем инвентаре — мод их сразу же выбросит),
- в любом сундуке/другом окне — выбрасываются только предметы из **вашего**
  собственного инвентаря, слоты сундука/торговли/печи не трогаются.

Выбрасывается сразу вся стопка найденного предмета (а не по одному), чтобы не
заспамить сервер — пауза между выбросами около 0.2 секунды.

## Ограничения

- Броня и дополнительный слот (offhand) не выбрасываются — только основной
  инвентарь и хотбар (36 слотов).
- Предмет летит в направлении, куда вы в этот момент смотрите (как обычный Q) —
  поставьте воронки там, куда направлена камера во время торговли.
- Многие серверы ограничивают автоматизацию — используйте там, где это разрешено.

## Сборка

```bash
./gradlew build
```
Готовый jar — `build/libs/itemthrower-1.0.0.jar`. Либо через GitHub Actions
(workflow уже в `.github/workflows/build.yml`) — jar появится в Artifacts.

Установка: jar + **Fabric API** для 26.1.2 в папку `mods` клиента.
